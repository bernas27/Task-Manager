## `01` — About the Project

**Task Manager** is a beginner-friendly project created to explore Node.js and strengthen my JavaScript skills through practical development.

The goal is to build a simple and useful way to manage everyday tasks while learning the fundamentals of backend programming.

## `02` — Features

- 📌 Create and manage tasks
- 📋 View existing tasks
- ✅ Track task completion
- 💾 Practice file handling and data persistence
- 🖥️ Interact directly through the terminal

*Features may evolve as the project develops.*

## `03` — Tech Stack

| Technology | Purpose |
|:--|:--|
| Node.js | JavaScript runtime |
| JavaScript | Application logic |
| File System (`fs`) | File handling and data storage |

## `04` — Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/bernas27/Task-Manager.git

# Enter the project directory
cd Task-Manager

# Run the application
node app.js
```
